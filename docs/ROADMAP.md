# WebBazaar — Engineering Roadmap & Phase Tracking

| Phase | Title | Focus Area | Status |
| :---: | :--- | :--- | :---: |
| **Phase 1** | **Foundation and Premium Public UI** | Next.js architecture, design system, responsive homepage, multi-vertical catalog, detail pages, typed demo dataset, automated Vitest and browser testing. | **COMPLETED** |
| **Phase 2** | **Authentication and Verified Sellers** | Supabase Auth integration, user profiles, RBAC roles (Buyer, Seller Applicant, Verified Seller, Admin), multi-step seller application, admin approval workflow, protected routes, audit logs. | **COMPLETED** |
| **Phase 3** | **Listing Management** | Seller listing creation & editing, multi-vertical draft workflows, Supabase Storage uploads for media and code archives, moderation queue. | *Planned Next* |
| **Phase 4** | **Marketplace Discovery** | Database-backed full-text search, pgvector / similarity search, dynamic category landing pages, seller public profile pages. | *Planned* |
| **Phase 5** | **Messaging and Customization** | Supabase Realtime chat between buyers and sellers, customization inquiry forms, formal custom milestone offer generation and acceptance. | *Planned* |
| **Phase 6** | **Orders and Digital Commerce** | Razorpay checkout integration, signed webhook signature verification, order status state machine, signed download URL generation with TTL. | *Planned* |
| **Phase 7** | **Business Acquisition Engine** | Acquisition inquiries, digital mutual NDA execution, private P&L document data rooms, assisted escrow settlement workflows. | *Planned* |
| **Phase 8** | **Admin Operations & Moderation** | Platform overview metrics, content moderation, dispute resolution, refund processing, comprehensive audit logs. | *Planned* |
| **Phase 9** | **Production Hardening** | Security audits, penetration testing, performance optimization, SEO validation, disaster recovery backups, production Vercel deployment. | *Planned* |
